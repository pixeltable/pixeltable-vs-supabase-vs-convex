# Security

This repo is a benchmark. It runs local models against synthetic fixture videos and holds
no user data.

The `.env.example` files contain placeholders only. If you find a real credential in this
repository or its history, please report it privately to security@pixeltable.com rather
than opening an issue.

For vulnerabilities in Pixeltable itself, see
[pixeltable/pixeltable](https://github.com/pixeltable/pixeltable).
