Pixeltable: Declarative Data Infrastructure for Multimodal AI

Pixeltable is an open-source Python library that unifies data storage, transformation, indexing, and
orchestration for multimodal AI applications. Unlike traditional approaches that require stitching
together separate services for vector databases, orchestration, and data pipelines, Pixeltable
combines all of these into a single declarative system.

Key Concepts:

Tables store structured and unstructured data with native multimodal column types including Image,
Video, Audio, and Document. When you insert a row, Pixeltable automatically runs any computed
columns — such as embedding functions, LLM calls, or image transformations — without requiring
separate pipeline code.

Computed Columns are the core abstraction. Instead of writing imperative pipelines that process each
row, you declare a transformation once and Pixeltable applies it incrementally on every insert. This
eliminates the need for orchestration frameworks like Airflow or cron-based embedding scripts.

Views provide virtual tables with iterators for efficient data processing. A FrameIterator extracts
video frames at a specified FPS. A DocumentSplitter chunks documents into sentences or paragraphs.
These iterators run lazily and incrementally.

Embedding Indexes enable built-in vector search with automatic maintenance. When you add an
embedding index, Pixeltable keeps it synchronized with the underlying data — no manual re-indexing
required when new data arrives.

Architecture:

Pixeltable runs on an embedded PostgreSQL instance, requiring zero external infrastructure to get
started. The same Python API works identically whether targeting a local embedded database or a
managed cloud instance. This local-first design means developers can build and test complete AI
pipelines on their laptop before deploying to production.

The serving layer provides both a CLI tool (pxt serve) and a Python API (FastAPIRouter) for exposing
tables and queries as HTTP endpoints. Routes can be declared in TOML configuration or programmatically,
supporting insert, update, delete, query, and compute operations.

Use Cases:

- RAG pipelines with automatic document chunking, embedding, and index maintenance
- Multimodal search across images, video frames, audio transcripts, and text
- AI agents with persistent memory, tool calling, and context retrieval
- Video intelligence with frame extraction, object detection, and temporal search
- Content moderation with automatic classification and flagging
