# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

This repo compares competing products. Criticism of the code, the methodology or the
conclusions is welcome and is the reason the repo exists. Disparagement of the people who
build any of these platforms is not.

Report unacceptable behaviour to conduct@pixeltable.com.
